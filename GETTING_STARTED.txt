📋 WHAT YOU NEED
═══════════════════════════════════════════════════════════════════════════════
✓ Python 3.8+ installed
✓ OpenAI API key (included in .env file)
✓ Any PDF document
✓ 5 minutes of your time


🚀 STEP 1: INSTALL (2 minutes)
═══════════════════════════════════════════════════════════════════════════════

Open PowerShell and run:

    pip install -r requirements.txt

Wait for completion. You should see:
    "Successfully installed streamlit langchain openai..."


🔑 STEP 2: VERIFY SETUP (1 minute)
═══════════════════════════════════════════════════════════════════════════════

Check that .env file exists and has API key:

    type .env

You should see:
    OPENAI_API_KEY=sk-proj-...
    OPENAI_MODEL=gpt-3.5-turbo


▶️ STEP 3: RUN APP (2 minutes)
═══════════════════════════════════════════════════════════════════════════════

In the same PowerShell window, run:

    streamlit run app.py

A browser window will automatically open to:
    http://localhost:8501


💡 YOUR FIRST CHAT
═══════════════════════════════════════════════════════════════════════════════

1. LEFT SIDEBAR: Click "Choose a PDF file"
   → Select any PDF from your computer

2. CLICK: "📤 Process PDF" button
   → Wait 2-5 seconds for processing

3. MAIN AREA: Type your question
   Example: "What is this document about?"

4. CLICK: Send (↑ button)
   → Wait 1-2 seconds for answer

5. VIEW: Answer with citations below
   → Shows page numbers and source snippets

6. CONTINUE: Ask follow-up questions
   → Chat history is maintained automatically


✅ VERIFY IT WORKS
═══════════════════════════════════════════════════════════════════════════════

Success indicators:
✓ PDF processes without error
✓ Answer appears with text
✓ "Sources" section shows citations
✓ Page numbers are displayed
✓ Follow-up questions work

⚠️ COMMON ISSUES
═══════════════════════════════════════════════════════════════════════════════

"Streamlit not found"
→ Solution: Run `pip install -r requirements.txt`

"OPENAI_API_KEY not set"
→ Solution: Check .env file exists in current directory

"No citations shown"
→ Solution: Use sidebar to increase # of sources (try 5)

"App crashes"
→ Solution: Check ./logs/rag_app.log for details
